## Defects found while building the validation harness

1. **`python -m cuda_engine.cli` silently did nothing and exited 0** — no
   `__main__` guard. The first draft of `validate_export.py` used it, so the
   export step would have "succeeded" while producing no package. Fixed by adding
   the guard (+2 subprocess tests), and the driver now confirms the package exists
   rather than trusting the exit code.
2. **The exported package ignored the run's nvcc flags** — it JIT-built with
   torch's defaults instead of the `-O3 --use_fast_math` the kernel was compiled
   and measured with, so the installed kernel would not have been the one
   `VERIFICATION.md` describes. Flags are now recorded in `manifest.json` and used
   by the loader.

Both were found by actually running the loop, not by reading the code.

## ⚠️ Open question before committing Rung 2: is the 1.11× fused speedup real?
It is internally inconsistent with the 0.06× bare fp16 result: GEMM cost is
O(N³) matmul, fusion only saves an O(N²) round-trip, so a non-tensor-core fused
kernel should NOT beat a cuBLAS-backed fused baseline. Two very different
explanations, needing the artifacts to distinguish:
1. the fused kernel used tensor cores (WMMA) while the bare one didn't → a
   genuine fused+tensor-core win (great), OR
2. the fused baseline was measured against something slow (a baseline artifact,
   like the v1.0 bug) → 1.11× is not real.
**Verify before Rung 2:** inspect `matmul_bias_gelu_fp16` `stage5_polish/.../kernel.cu`
(does it use `wmma`/`mma`?) and the `stage4_performance/.../benchmark.json`
(`baseline_mode`, `baseline_ms`, `custom_ms`, benchmark shape) for all three.

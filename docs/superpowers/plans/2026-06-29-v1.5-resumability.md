# Synthesis-Stage Resumability Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Resume a single kernel's synthesis run from the first incomplete stage, reusing completed stages' persisted outputs (zero LLM calls) and refusing to resume against changed inputs.

**Architecture:** The orchestrator writes a `checkpoint.json` (inputs fingerprint + completed stages + the rehydratable objects) after each stable stage boundary. `Orchestrator.run(resume_run_id=...)` loads it, validates the fingerprint, re-hydrates `KernelSpec`/`KernelArtifact`/`CorrectnessReport`/`PerformanceReport` from the stored JSON, and continues from the first incomplete stage. Default (no-resume) behavior is byte-identical.

**Tech Stack:** Python 3.11, pydantic v2, pytest. All tests use the mock LLM/GPU/store — no hardware.

**Spec:** `docs/superpowers/specs/2026-06-29-v1.5-resumability-design.md`.

## Key facts about the existing code
- `Orchestrator.run(*, prompt, reference, target)` in `src/cuda_engine/orchestrator.py`: `run_id = self.store.new_run()`; writes `inputs/prompt.txt`, `inputs/config.json`, `inputs/reference.py`; then sequential stages (interview → codegen-with-escalation → correctness + repair loop → performance → polish) → `report.json`.
- Rehydratable objects + their stored form:
  - `KernelSpec` (frozen) — `stage1_interview/kernel_spec.json` (written by Stage1Interview).
  - `KernelArtifact` (frozen): `kernel_cu_path: Path`, `kernel_so_path: Path | None`, `compile_log: str`, `ptx_size_bytes: int` — `.so`/`.cu` files live in the run dir; rehydrate via `model_validate` (paths become strings via `model_dump(mode="json")`).
  - `CorrectnessReport`, `PerformanceReport` (in `models/reports.py`).
- `ArtifactStore` (ABC, `services/store/base.py`) is write-only today: `new_run`, `run_dir`, `write_text/bytes/json`. Impl: `services/store/local_dir.py`; mock: `services/store/mocks.py`.
- `_reference_source(reference)` in orchestrator.py already extracts reference source for fingerprinting.

## Resumable checkpoint boundaries (the four stable points)
`interview` (spec done) → `correctness` (a PASSING artifact exists; subsumes codegen + repair loop) → `performance` (perf report + artifact) → `polish` (done). The codegen/repair loop is NOT a separate resumable point (within-stage; YAGNI). Resume re-hydrates and skips to the first boundary not yet completed.

```python
from __future__ import annotations
import hashlib
from typing import Any
from pydantic import BaseModel, Field

class Checkpoint(BaseModel):
    inputs_fingerprint: str
    completed_stages: list[str] = Field(default_factory=list)
    objects: dict[str, Any] = Field(default_factory=dict)

def compute_fingerprint(*, prompt: str, reference_src: str, target: str) -> str:
    h = hashlib.sha256()
    for part in (prompt, reference_src, target):
        h.update(part.encode("utf-8"))
        h.update(b"\x00")
    return h.hexdigest()
```

## Chunk 3: Resume

### Task 4: `resume_run_id` — load, validate, rehydrate, skip
**Files:** Modify `src/cuda_engine/orchestrator.py`; Test `tests/unit/test_orchestrator_resume.py`.

- [ ] **Step 1: Failing tests**
  - *Resume skips completed stages:* run with a mock LLM that raises `RuntimeError` when invoked during the performance stage (so the run dies after `correctness` is checkpointed).   - *Fingerprint mismatch:* resume the same run_id with a different `prompt` → raises a clear error (message mentions resume/inputs changed).
  - *Missing checkpoint:* `resume_run_id` with no checkpoint.json → clear error.
- [ ] **Step 2: Run, expect FAIL.**
- [ ] **Step 3: Implement** — at the top of `run`, if `resume_run_id` is set: `run_id = resume_run_id` (skip `new_run()`); load checkpoint via `store.read_json`; if absent → raise; recompute fingerprint and compare → mismatch raises; rehydrate `spec = KernelSpec.model_validate(objects["spec"])`, and for each completed boundary the corresponding object (`KernelArtifact`/`CorrectnessReport`/`PerformanceReport` via `model_validate`). Guard each stage block: `if "interview" in completed: spec = <loaded>` else run interview; similarly skip codegen+correctness when `"correctness" in completed` (use loaded artifact + correctness); skip performance when `"performance" in completed`; skip polish when `"polish" in completed` (return the already-complete result). If a referenced artifact file is missing on disk, treat that boundary as incomplete and re-run from there (graceful degrade). Keep guards readable; extract a small `_resume_state(...)` helper if `run` gets unwieldy.
